TRENDORA 쇼핑몰 과제 프로젝트

구성
- index.html : 쇼핑몰 화면
- style.css : 디자인 및 반응형 스타일
- script.js : 상품 데이터, 회원/주문/장바구니 기능
- img/ : 메인 배너 및 상품 사진(JPG)

이미지 안내
- img 폴더에는 TRENDORA의 미니멀한 블랙·화이트 패션 무드에 맞춘 생성형 패션 예시 사진이 들어 있습니다.
- 상품별 사진은 서로 다른 이미지로 구성했습니다. 실제 판매 상품의 실물 촬영 사진은 아닙니다.

실행 방법
1. ZIP 압축을 풉니다.
2. index.html 파일을 브라우저에서 엽니다.
3. 회원가입, 로그인, 상품 상세, 장바구니, 체험 주문 기능을 확인합니다.

GitHub Pages 배포
1. GitHub에서 새 Repository를 만듭니다.
2. index.html, style.css, script.js, img 폴더를 저장소 최상위에 업로드합니다.
3. 저장소 Settings > Pages로 이동합니다.
4. Deploy from a branch를 선택하고 main / (root)를 지정한 뒤 Save를 누릅니다.
5. 잠시 후 표시되는 GitHub Pages 주소로 접속합니다.

주의사항
- 회원/장바구니/주문 데이터는 브라우저 localStorage에 저장되는 수업용 데모입니다.
- 실제 서버 데이터베이스, 결제, 배송 기능은 연결되어 있지 않습니다.
- 비밀번호는 데모 목적으로 브라우저에 저장되므로 실제 서비스에 사용하면 안 됩니다.
